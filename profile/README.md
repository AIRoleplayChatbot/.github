**Core idea**

These are not general assistants. You pick or build a character, send messages, and can return later. Free tiers are short. Images and voice usually require paid plans.

**Flow**

- Open the site  
- Select or create character  
- Test messages  
- Stay in thread  
- Upgrade if needed
